# RAG Chatbot dependencies
# Domain-driven architecture with clear separation of concerns.

# torch/torchvision/torchaudio and paddlepaddle are installed separately (see
# Dockerfile) since both need a hardware-specific index URL (CPU vs CUDA
# build). For a local venv:
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
#   pip install paddlepaddle==3.2.0 -i https://www.paddlepaddle.org.cn/packages/stable/cpu/
# Pin paddlepaddle to 3.2.0, not 3.3.x — 3.3.0's oneDNN/PIR CPU executor is
# broken for text detection (confirmed by running real OCR inference against
# this repo's code; upstream bug PaddlePaddle/Paddle#77340).
